# AI 101 writing style

Every Lesson — English source and each translation — follows these rules. The
Learner is a curious non-technical adult who has heard of ChatGPT and maybe tried
it once. Write for that person.

## Reading level

- Aim for roughly an **8th-grade** reading level.
- Keep most sentences **under 20 words**. Break a long sentence into two.
- Prefer short, common words. "use" not "utilise", "enough" not "sufficient".
- One idea per paragraph. Two to four sentences is a good paragraph.

## Jargon

- Define every technical term **in plain words the first time you use it**, in
  the sentence where it appears. Example: "a **large language model** (LLM) — the
  engine inside tools like ChatGPT".
- After defining a term, use it plainly. Don't re-explain it every time.
- Avoid terms the Lesson doesn't need. If you can make the point without
  "parameters" or "inference", do.

## Voice

- Write in the **second person**: "you", "your prompt".
- Warm and direct, not cutesy. No mascot voice, no exclamation-heavy hype.
- It's fine to be plain-spoken about limits: "it can sound sure of a fact that is
  wrong".

## Examples

- Use **concrete everyday examples** over abstractions: an email to a landlord, a
  recipe, planning a trip.
- Show, don't assert. A before/after prompt beats a paragraph about prompting.

## Tone on AI itself

- **No hype**: don't call it magic, revolutionary, or superhuman.
- **No doom**: don't frame it as dangerous, sentient, or about to take over.
- It's a useful tool with clear strengths and clear failure modes. Say that.

## Structure

- Start the Lesson with why it matters to the Learner, in a sentence or two.
- Use short `##` section headings that state the point.
- End with a one-line bridge to the next Lesson.

## Try-It callouts

- Give the **exact prompt** to paste into a real tool.
- Add one line on **what a good response looks like**, so the Learner can judge
  the result.
- Never imply the app itself will run the prompt.

## Knowledge Check

- 3–4 questions. Each checks one key point from the Lesson.
- Every option — right and wrong — gets a one- to two-sentence explanation that
  teaches something. A wrong answer should leave the Learner more correct.
- No score, no pass mark, unlimited retries. Don't write "you failed" language.
